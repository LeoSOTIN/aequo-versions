# Politique de confidentialité — ÆQUO RH

*Mise à jour le 19/11/2026. Éditeur : Léo SOTIN — sotin.logiciels@gmail.com*

## Vos données restent chez vous

ÆQUO ne collecte aucune donnée. Rien de ce que vous saisissez ou importez n’est envoyé à l’éditeur : ni noms,
ni heures, ni fiches de paie, ni statistiques d’utilisation. Il n’y a ni compte à créer, ni publicité, ni
mesure d’audience.

## Ce que ÆQUO enregistre sur votre ordinateur

Pour calculer les heures supplémentaires et les congés payés, et pour les comparer aux fiches de paie, ÆQUO
enregistre sur votre ordinateur, et seulement là, les informations que vous lui donnez :

- le nom de chaque salarié suivi, son contrat et ses horaires (saisis par vous) ;
- les heures travaillées, lues dans les feuilles d’heures Excel que vous importez ;
- les fiches de paie que vous importez : leur texte complet, les montants de salaire (brut, net, net
  imposable), les heures supplémentaires payées et les congés payés. Ce texte peut contenir d’autres
  informations imprimées sur la fiche, comme l’adresse ou le numéro de sécurité sociale ;
- les absences, avec leur motif (par exemple maladie) et les justificatifs que vous choisissez de joindre ;
- les documents internes et les contrats que vous choisissez d’enregistrer ;
- vos réglages, et le journal des opérations effectuées dans le logiciel.

Les montants de salaire, les motifs d’absence et les justificatifs sont des informations sensibles. ÆQUO ne
les enregistre que parce que vous les importez ou les saisissez vous-même, et ne s’en sert que pour les
calculs et les contrôles que vous voyez à l’écran. À la première ouverture, ÆQUO vous le dit et vous demande
votre accord avant tout enregistrement.

## Où, et comment elles sont protégées

- Installé depuis le Microsoft Store : dans le dossier `AEQUO` de votre dossier personnel
  (`C:\Users\<votre nom>\AEQUO`). Installé avec l’installateur classique : dans `%LOCALAPPDATA%\AEQUO`.
- La base est chiffrée ; sa clé est protégée par votre session Windows. Les comptes d’utilisateur que vous
  créez dans ÆQUO sont protégés par un mot de passe.
- Les sauvegardes que ÆQUO fait lui-même restent dans ce dossier, chiffrées elles aussi. Un export ou un
  fichier projet que vous enregistrez ailleurs est sous votre responsabilité.

## Durée de conservation et suppression

Les données restent tant que vous ne les supprimez pas. Vous pouvez à tout moment :

- supprimer un dossier de salarié, une feuille, une fiche de paie ou une absence depuis l’écran concerné ;
- tout effacer avec Paramètres › Réglages avancés › Sauvegardes › « Configuration d’usine » ;
- avant de désinstaller ÆQUO, utiliser Paramètres › À propos et confidentialité › « Préparer la
  désinstallation » : les tâches programmées dans Windows (captures automatiques, rapports annuels) sont
  retirées, et vous pouvez effacer toutes les données.

Désinstaller ÆQUO ne supprime pas vos données : elles sont reprises si vous le réinstallez. Pour qu’il ne
reste rien, utilisez « Préparer la désinstallation », ou supprimez le dossier indiqué ci-dessus après la
désinstallation.

## Les données de vos salariés

Si vous suivez dans ÆQUO les heures d’autres personnes que vous, vous êtes responsable de leurs données au sens
du Règlement général sur la protection des données (RGPD) : c’est vous qui les collectez et qui décidez de
leur usage. L’éditeur n’y a jamais accès.

## Les seules connexions à Internet

- **Mises à jour.** Installé depuis le Microsoft Store, ÆQUO est mis à jour par le Store, comme toute
  application du Store. Installé avec l’installateur classique, ÆQUO lit à l’ouverture le numéro de la dernière
  version publiée : rien n’est envoyé, sinon ce qu’envoie toute visite d’un site (votre adresse IP).
- **Conditions d’utilisation.** À l’ouverture, ÆQUO lit aussi sur le site de l’éditeur (GitHub) une éventuelle
  annonce de passage à une utilisation payante, prévue par sa licence. Là encore, rien n’est envoyé, et une
  clé de licence se vérifie sur l’ordinateur, sans connexion.
- **Horodatage d’un export figé (seulement si vous le demandez).** Seule l’empreinte du document est transmise
  à un service d’horodatage (freetsa.org, puis DigiCert en secours) : une suite de chiffres de laquelle on ne
  peut rien reconstituer. Le document lui-même ne quitte pas l’ordinateur.
- **Consultation sur téléphone (seulement si vous l’activez).** Une page par salarié est mise en ligne sur
  l’hébergement Cloudflare que vous avez vous-même créé. Elle est chiffrée par le code du salarié : sans ce
  code, elle est illisible, y compris pour Cloudflare et pour l’éditeur.
- **Liens vers les textes officiels.** Légifrance et le Code du travail numérique s’ouvrent dans votre
  navigateur, comme tout lien.

## Signaler un problème

ÆQUO peut préparer un fichier .zip à joindre à un e-mail que vous envoyez vous-même. Il ne contient que la
configuration et le journal technique, masqués : aucune donnée sensible. Vous voyez son contenu exact avant de
l’enregistrer, et ÆQUO n’envoie rien lui-même.
